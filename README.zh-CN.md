
# dsh-canvas-flow

[English](./README.md) | **简体中文**

> **在画布上，搭出你的工作流。**
> 拖拽成流程，连线传数据，每一步都看得见。

**dsh-canvas-flow** 是跑在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上的**无限画布插件**：一个项目铺在同一张画布上 —— 文本卡片写规范、设计卡片出设计稿、应用卡片做出能跑的 Web 应用，还能在预览里按元素精修。

卡片之间用连线引用，上游的产物直接喂给下游，几个卡片配合起来就能完成大型复杂任务。

---

## 主要功能

- 通过文本卡片生成需求文档，通过设计卡片生成网站设计或者 PPT，通过应用卡片生成 web 应用，通过图片 / 视频卡片生成画面与短片。
![alt text](docs/images/dsh-canvas.png)

- **项目目录按卡片类型分文件夹**：产物不再平铺在画布根上——文本进 `docs/`、应用进 `apps/`、设计进 `designs/`、图片进 `images/`、视频进 `videos/`、音频进 `audio/`（另有 `data/`、`files/`、`folders/`）。
  老画布**第一次打开时自动整理**：只搬平铺在根上的条目，一件一条、撞名加序号、搬不动就留在原地；根上的 `index.html` 与你已经整理好的子目录都不动。

- 所有卡片类型都支持导出。
  - 文本卡片：支持导出 Markdown、纯文本本文档、Word 文档、PDF 文档。

  ![alt text](docs/images/export-txt.png)

  - 设计卡片：支持导出 Figma 文件、图片、PDF、PPT。

  ![alt text](docs/images/export-design.png)

  - 应用卡片：支持导出 web 应用压缩包，双击 index.html 运行即可。

## 安装插件

在插件市场中搜索 dsh-canvas-flow，点击安装即可。

## 路线图

### 已实现

| 能力 | 现状 |
|------|------|
| **文本** | Agent 生成 Markdown 文档，支持导出 Markdown 文档、纯文本本文档、Word 文档、PDF 文档 |
| **设计** | Agent 生成设计稿， Agent 精确二次修改指定图层。可导出 Figma 文件、图片、PDF、PPT |
| **应用** | Agent 生成 web 应用代码，支持直接在 DeepSeek Harness 客户端运行。支持指定元素， Agent 精确二次修改指定元素的代码。 |
| **图片** | Agent 生成画面（即梦 / Seedream），落在卡片产物上，支持图生图；会话里接着说就接着改。可导出原图，也可从本机导入一张当产物 |
| **视频** | Agent 生成短片（即梦 / Seedance），可给比例、时长、分辨率；按分钟计的异步任务，等它跑完。可导出原片，也可从本机导入一段 |
| **音频** | Agent 生成音频（豆包 `doubao-seed-audio-1-0`）：对白、音效、配乐、环境声写进一条 prompt；同步返回，单次最长 120 秒。可导出原文件 |

媒体节点的生成走**宿主自己的模型配置**：在 DeepSeek Harness 的模型设置里加一条能服务
Seedream / Seedance / Seed-Audio 的 provider 路线（填好 `baseURL` 与 `apiKeyEnv`）即可，插件这边不用改配置。
找不到可用路线时，卡片会如实说出「按什么找的、去哪儿加」。

音频注意一件事：`doubao-seed-audio-1-0` 挂在方舟的模型广场上，但**接口在豆包语音**——
地址、密钥与方舟都不是同一套（鉴权是 `X-Api-Key`，不是 Bearer）。推荐给它单独一条路线：

```yaml
doubao-audio:
  apiKeyEnv: ARK_AUDIO_KEY        # 语音控制台拿到的 API Key
  baseURL: https://openspeech.bytedance.com/api/v3
  models:
    - id: doubao-seed-audio-1-0
```

只写一条方舟路线也能跑（插件会把音频请求改投语音那条主机），前提是那把 key 两边都认；
不认时 401 的文案会直接告诉你该去加哪一条。

**卡片上直接就是产物本身**：图片卡是那张图，视频卡与音频卡各是它们的原生播放器——能在这里
播，也能拖进度条。全画布只有一种卡片尺寸**400×252**，媒体卡的卡面**正好 16:9**：卡面就是画面，
200 宽里一张 16:9 的图只剩一条窄带；而高度若按两倍（280），16:9 的图上下会各空出一条底色
——高度得由面板 16:9 反推（398×224 + 卡头 26 + 边框 2）。音频卡与别的卡同尺寸（v1.79 起全画布只有一种节拍）。卡面与双击全屏**读的是同一条产物、说同一批话**（文件还没生成 / 文件过大）。

**「这段对话用哪个模型」与「这张卡由哪个模型生成」是两件事，同一个下拉框问两件事**：文本 /
设计 / 应用卡上，它选的是这段会话下一次请求用哪个模型（所以只列能对话的——Seedream / Seedance
选进去只会让下一次对话失败）；图片 / 视频 / 音频卡上，它选的是**这张卡由哪个模型生成**，只列
这一族（图片卡列 Seedream、视频卡列 Seedance），写在这张卡自己身上，**不碰会话**。没选过时
显示「自动」，意思是按模型族去上面那条 DSH 模型配置里挑。选了就真的用这个——配置里没有它时
卡片会如实报错（不会悄悄换一个去画）；这个选择跟着作品走，换台机器打开同一份目录仍然生效。

**引用一张图就能图生图 / 图生视频**：从图片卡连一条线到图片卡或视频卡，生成时那条边就变成
参考图（图像生图的 `image`、视频的首帧）——不用先把图发布成链接。视频还能指定它是首帧
（默认）、尾帧还是参考图。
